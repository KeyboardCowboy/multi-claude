MultiClaude

Run Claude Desktop for All Your Accounts at Once

    Authenticating

    When first authenticating a Claude account, all Claude instances need to be closed so the browser redirect sends you back to the right window. Open the ⋯ menu on a profile and choose Sign in or connect… to have MultiClaude do this for you. The same goes for connecting a service.

    After you’re authenticated, you can open a new Claude instance just by clicking the profile card.

    How it Works

    Claude Desktop keeps your sign-in, settings, and connectors in a single data folder. MultiClaude gives each profile its own folder and starts Claude pointed at it, so every profile runs as a separate copy of Claude with its own account.

    Personal Claude uses Claude’s usual folder, so the account you already use stays signed in. Every profile also keeps its session history there, filed by account, just as Claude Desktop does on its own. Signing into an account the normal way shows the same history, and nothing is lost if you stop using MultiClaude. This relies on a standard option of the framework Claude Desktop is built on, not an official Claude feature, so a Claude update could change how it behaves.
